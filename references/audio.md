# 原动作声音、动画式重量与配乐

## 音轨政策与清理

先沿用用户要求：仅留原声、允许原声派生，或允许另配授权音效。参考动画用于分析起音、停顿、调制和尾部，不默认授权取样原作声音。硬币、袋口、玻璃、响指各用自己的原始录音，不变成同一种炮声。

遍历整条录音找齐事件，保留起音前少量预卷与自然尾部。用附近安静区估噪，短窗降噪/门限/渐变裁切避免削起音；事件外可静音，但重叠杂音未必能靠门限去除。说明配音含音乐时按授权本地分离，检查辅音与水声伪影，不宣称完美分离。模型下载和远程服务遵循本次授权，技能不预授权限。

## 分层

| 层 | 实施与检查 |
|---|---|
| 干接触 | 独立保留起音、脆度、材质和音高，先分配余量 |
| 蓄力/电弧 | 原声倒吸、摩擦或授权纹理随换稿加密，爆前短收声制造反差 |
| 可听主体 | 从本动作低中频微结构派生，约 80–250 Hz 是探索范围；小扬声器也要有重量 |
| 深低频 | 从可信短段降调/伸展并限带，或按允许政策选设计声；居中、相位稳定、增益有界 |
| 破裂攻击 | 原声高频/材质、短饱和或授权裂响补咬合，长噪声不能吞掉接触 |
| 压力尾部 | 按强度与材质改变衰减，给下一事件、对白与结尾让位 |

先选有效微结构再降调，避免金属高频被拉成所有物体一样的 sub。近静音、呼吸和底噪不得无限放大。每个物体的中心频带、微节奏、尾长与空间响应按自身素材调整。递进通过攻击/压力关系、铺垫反差和尾部组织实现，不只增益递增。

## 爆发与混音

极低正弦可能只有能量没有拳感，必须有可听主体、谐波和攻击。加 sub 后给整个 cue 峰值归一化会一起压弱干响指，前两下尤其容易被掩盖。分层留余量，总线只控制必要越界峰值，不为固定 RMS 无限压缩。

低频中心化，检单声道抵消、拍频与相位；不要随意用负延迟让 sub 抢拍。以原声真实起音而非裁切窗口开头对齐，核对解码后的编码延迟。

配乐在接触与对白时用局部音量、频谱自动化让位，保留主高潮音乐的释放，不持续压扁整首。同窗测干接触/伴奏，实际试听不同设备；无通用 dB 比例。过量低频会抢对白和限制器余量，反而盖掉脆声。

解码交付音频后检查过采样峰值和余量，-1 dBTP 可作常用起点，按平台调整。4×过采样只是工程峰值估计，不冒称认证标准仪表；AAC/MP3 后重测。谱能量、同步、响度和听感分别记录，无听觉条件不写“听感已通过”。

## enhance_contact.py

输入已定位、只含一个主要动作的 WAV，`--onset` 是输入中的起音秒，不是成片秒：

`python scripts/enhance_contact.py contact.wav --onset 0.10 --out enhanced`

默认提取起音前 6 ms、后 0.45 s。输出干声、主体、sub、限制前相加和、主处理差分、母版与报告。报告含输入窗口起点、窗口内真实起音样本、派生比例和峰值。新 cue 放在成片 `target_onset - onset_sample/sample_rate`，不能把预卷开头直接放在拍上。

工具不自动去噪或识别语义，先清理再运行。派生层使用当前原波形、确定性重采样和限带，增益有上限，静音不产生冲击。`--body-db`、`--sub-db` 是混入比例，不是目标响度；按动作调，不照搬。该助手不替代完整音乐/对白混音或听审。

交付分轨和主处理配置。非线性处理后母版不等于干分轨直接相加，附处理差分或完整链。只改声音可复制视频码流核对 payload；只改画面可复制音轨核对 payload。封装文件整体哈希不用于证明媒体码流相同。
