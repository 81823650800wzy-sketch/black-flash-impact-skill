# 节奏、卡点与连续源时间

## 三种时钟

分开音乐文件绝对时间、裁切后成片时间、原视频时间。音乐开头无声也属于原文件时间；记录真实入点，不以“约十几秒静音”反复改写时间码。

`output_time = (music_source_time - music_in) / music_speed`

默认音乐原速；每个落点独立 `round(output_time * fps)`。帧率用有理数，不累积四舍五入后的每拍帧数。成片第 0 帧、Blender UI 第 1 帧和音频采样起点分别记录。VFR 使用实际 PTS；脚本需 CFR 时先规范化并保存映射，不将帧号/fps冒称所有文件的真实时间。

事件表保存 ID、源素材、源接触 PTS/帧、原声起音、音乐绝对秒、输出帧、预备/接触/恢复范围、强度职责和证据等级。音频最大峰不一定是可见接触，须看连续帧；相机录音传播与设备延迟另查。

## 节奏层级与编排

区分基础脉冲、拍内小鼓点、完整重复节奏、乐句和大转折。BPM 不给第一拍，最响峰不自动是高潮；人声、贝斯与失真也能形成瞬态。检查释放前、释放时和后续连续窗口，保留半速/倍速和切分候选。没有可靠听辨就把 BPM、鼓种和乐句写成估计。

“八个循环”可能指八轮完整节奏或八个强拍；两者会改变主体时长时澄清，已有答案不再问。单轮密集版可把多个不同动作压进一次动机，每个真实接触响应一个明确小重音，留出收尾。多轮版才按要求设计短倒放、故障、滤镜与重放；每次重放重新对齐接触和声音，避免无目的地爆满。

卡的是接触/爆发，不只是切镜。先做净剪，铺垫内部不能已有更大爆发抢掉音乐释放。说明原声完整、字幕阅读、前序事件等约束进入排程，不能为高潮对齐删掉用户要求保留的内容。

## 连续变速与曝光保护

用源时间函数 `s(t)` 统一摄影、追踪、蒙版、粒子与环境状态；采用速度积分或单调 PCHIP，禁止 `s=t*v(t)`。钉 `s(t_hit)=s_hit` 后仍要保护完整关键曝光序列；单点正确不能阻止跳稿。

连续 take 源时间前进、构图和环境包络连续。收手可加速，缓动蓄力，接触前提速；范围按动作可辨性确定。检查旧分段边界的源帧号、手势、背景、缩放与曝光，防止源片没切、构图却重置的隐性跳镜。倒放是明确的独立段，不塞进单调正放曲线。

优先对净摄影做映射，再按输出帧绘制手绘曝光；保留旧稿时锁住整个曝光窗口。光流容易揉坏手指、细碎粒子、反相和黑白线条；可用原生采样/重复帧并说明限制。重复帧不增加运动信息，双帧混合会软化边缘，不默认用于整条合成片。

声音以样本级落点放置，原接触音可独立保音高，不机械变速整条对白/配乐。新增停顿后重算后续 cue；倒吸、换稿声和尾部跟随新的输出时钟。

## plan_timing.py 契约

`python scripts/plan_timing.py examples/timing.json --out timing-result.json`

输入 `fps`、`duration`、`music.in`、可选 `music.speed` 和 `events`（唯一 ID、`music_time`、`source_time`）。秒从零开始。`continuous_takes` 含 ID、`source_fps`、输出起止秒、控制点 `[output_seconds, source_seconds]` 和 `protect` 接触保护列表；每项指定 `event`、前后输出帧数、可选播放速度（默认 1）。同一 take 的事件必须来自同一源视频。

工具将接触量化到输出帧，保护窗口在量化后帧锚定原片接触秒，逐帧加入等速保护点；拒绝冲突、负源时间、倒退及越界。take 范围左闭右开，控制点可在右边界。PCHIP 插值的是时间，不是图像。输出源秒/最近源帧、速度范围与量化误差；源片总长、PTS 与语义仍须调用方检查。控制点与误差证明排程一致，不证明拍点选得正确。
